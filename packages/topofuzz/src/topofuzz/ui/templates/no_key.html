One quick setup step.

topofuzz uses Google's Gemini models to test your AI pipeline. We need a Gemini API key — it stays on your computer.

Get a Gemini API key

  1. Open aistudio.google.com/apikey.
  2. Sign in and click Create API key.
  3. Copy the key (it starts with AIza...).

Tell your computer the key

Set the environment variable GEMINI_API_KEY and restart topofuzz. The exact command depends on what shell you use.

PowerShell (Windows) 
$env:GEMINI_API_KEY = "AIza...paste-yours-here"
python -m topofuzz ui
bash / zsh (macOS, Linux) 
export GEMINI_API_KEY="AIza...paste-yours-here"
python -m topofuzz ui

Once the key is set: stop topofuzz (Ctrl+C) and run python -m topofuzz ui again in the same window. Refreshing this page alone won't pick up the new key — a running process keeps the environment it started with.
